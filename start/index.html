Doors and menus

Click a door to open it. Rest on a door with a small arrow and its menu drops down with the views inside, so Admin → Messages or Coaches → Try-outs is one click. You only see the doors and views you have been given.

Jump anywhere

Press ⌘K (Ctrl+K on Windows) or click the search and type a page, a report or a view. Inside a page the tabs are the pills under the title; the top bar never changes.

Every screen has an address

Admin → Messages is /backend#messages. Paste a link in Slack and it opens exactly that screen. On a phone the bar folds to the essentials and the Dashboard tiles do the same job as the doors.
